# 0.2.8 变更与验证（2026-11-08）

## 变更

Coop Assist 的 BepInPlugin、客户端扩展、服务端扩展统一为 0.2.8。SSMP.dll 仍固定 0.4.142（SHA256 71E10C6808C24AB0F01E5B48CB463955A179166914652C9C4B16D9F380D11354）。

1. 定向队友传送：ModMenu/F7 选择目标；默认 F6，可改键。新 TeamTravel 枚举值追加在既有两个 ID 后，不改变颜色/房主集合旧封包。双向集合封包防止三人同时请求/应答时相互覆盖。服务器按已认证发送人、唯一请求号、指定目标和期限路由。客户端主线程处理回应；正常入口转场、加载后检查本机安全地面，目标掉线/倒地/离开场景则取消。请求不改变对方位置，不使用死亡复活作为传送方式。
2. 解除成员等待：前置阻止 CoopSave.Hold，用原生 ReleaseHold 清理其自身持有的控制锁；不直接 RegainControl、不触碰死亡旗标。TryOpen 不再要求有历史成员在线，也不把存档转为单人；IsGroupComplete/HasAllMembers 只要求当前在线成员完成原生校验。大厅准备流程保留原生握手；双方均准备后选档，备份和快照接收仍沿用原生流程。
3. 返回长椅改键：保存到插件 Play.ReturnToBenchKey，并修改原生 CoopLeave 的键盘绑定；移除旧键盘/鼠标绑定，保留 DeviceBindingSource。提示继续由原生 PromptKeyName 读取实际绑定。原有救援/复活协程保持不变。
4. 入房先同步：在原生 CoopHostSync.Merge 成功后、原生 PendingJoin 加载前，将字段策略中的能力/进度改为房主值，并按房主确切数量覆盖材料、ShellShards、工具、纹章/装备、丝线、针升级、面具/丝轴、任务/图鉴等资源。Collectables 整体按房主，Rosary_Set_* 恢复自己的原条目；geo、TempGeoStore、dicePilgrimBank、CrawbellCurrency 保持个人。复入不会累加资源。健康值至少为 1，避免房主倒地的快照让加入者以死亡状态出生。沿用原生模式兼容检查、自动备份和个人世界对象分类，避免复制个人念珠拾取/碎石平台。缺失房主快照时不走“按原档进入”的回退。

个人皮肤、UI、Aa轩辕体 27 磅、颜色同步、运动滤波、受击反馈及 0.2.7 收包/信号修订均保留。

## 设置列表滚动修订（版号仍为 0.2.8）

联机体验由 SimpleMenuScreen 改用 ModMenu 0.8.0 自带的 ScrollingMenuScreen，并限制为纵向滚动。原生 ScrollingPane 提供裁剪视口、溢出时显示的右侧滑块、滚轮和选择焦点跟随；BackButton 继续留在 BasicMenuScreen 的 ControlsPane 内，不随列表滚动，防止最后两项改键设置覆盖返回键。原生滚动视口默认 1510 × ceil(105 × 8.334) 画布单位，十项设置超出视口时可滚动。未调整游戏整体 UI 字号或缩放。

编译及原生接口检查通过；打包 DLL 的 BuildCustomMenu 构造及 AddTravelMenu 参数均指向 ScrollingMenuScreen，F5 默认键和 0.2.8 版本标记保留。字体、颜色、网络与传送源码未改动。未启动游戏，实际分辨率下的鼠标/手柄滚动表现尚需实机确认。

## 大厅准备回归修复（版号仍为 0.2.8）

删除 SessionFreedom 对 ClientManager.OnClientConnect 的 ChooseSaveWithoutReady 后置补丁。旧补丁直接调用 OpenSaveAfterReady，导致客机在发出 WaitingRoomReady 前离开准备界面，而房主的 RefreshWaitingRoom 仍要求客机 Ready，形成互锁。恢复原生大厅握手：加入后可点击准备，满足条件后各端才选档。游戏内 Hold/长椅等待解除及在线组校验补丁继续保留；不绕过房主快照、备份与资源同步。

新增 70 项大厅流程检查通过（使用原生方法体的模拟）；增加准备流程回归检查：禁止辅助插件在连接事件中直接调用 OpenSaveAfterReady；检查原生准备事件连线及游戏内解除等待补丁保留。用固定版本原生 RefreshWaitingRoom 等方法体进行无界面的双人/三人状态流模拟，覆盖先后准备、未准备不选档、队友离线、已在游戏内的迟加入、客机旧补丁导致房主卡住的复现。该模拟不执行 Unity 或网络。F5、滚动菜单、Aa 27 磅与名字颜色源码不变；仍需真实两端/三人复测。
