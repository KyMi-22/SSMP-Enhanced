# 0.3.0-preview 验证记录

Coop Assist 修订 20261112-grand-gate-maps，基于 SSMP 0.4.142。预览版沿用该修订的圣斐巨门与共享地图实现。

- 发布包、清单和启动日志使用 `0.3.0-preview`。BepInEx 读取数字 `0.3.0`，模组名显示 Preview。SSMP 的联机标识为 `0.3.0-pre`，符合原生的 10 字符上限。房主和客机需安装同一预览版。
- 两种安装包附带上一版 0.2.9 同修订的 DLL，可按安装说明回滚。
- 编译、原生接口检查及全量回归通过。进度一致性和三人共享地图模拟通过。圣斐巨门场景切换、快捷地图及商人货架仍需双人实测。
- 客机若在房主收到购买记录前退出，重进以房主快照为准。两人若在共享到达前同时确认购买，仍可能各自扣费。
