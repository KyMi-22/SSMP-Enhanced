# 0.2.6 本地修订验证

按用户要求，DLL 的 BepInPlugin、客户端及服务端扩展、当前安装包与说明统一使用 0.2.6。此前误递增的本地标号不代表新版本发布。本批后续修补不自动递增版本号。

运行代码保留已完成的原生角色换肤优先、UI 异步补刷、最新选择排队、失败只恢复 UI、存档页延后激活刷新，以及基于 Windows 字体的旧 TMP 中文名字补全。本次统一编号未删除这些修复，也未改动它们的实现。

本次编译通过，BepInPlugin 和双方扩展版本均从实际 DLL 核对为 0.2.6；名字字体挂钩仍针对 TMProOld.TMP_FontAsset。4,005 项名字字形/UV 坐标检查通过；其他原有逻辑回归与 109 项换肤模拟沿用同一实现最近一次通过的结果。安装包重新检查所有运行文件大小及 SHA256。

尚未启动修订版实际游戏、进行双机或 GPU 字体栅格化实测。初始问题仅有用户反馈；本机运行日志为回滚后 0.2.5，没有将其当作故障版的实机复现。

字体修复只在原字库缺字时生成名字所需的动态 SDF 字形，转换为旧 TMP 的 FaceInfo、TMP_Glyph、材料及单向多页回退。已用实际程序集核对旧 TMP 纵向纹理坐标自顶部计的规则，保持旧组件的颜色、字号、粗体与显示开关。不附带 Windows 字体文件；覆盖范围取决于本机字体。

回退附件仅为用户已使用的 0.2.5。旧编号的本地产物移至 dist/obsolete-labels，作为历史材料，不作为新版本提供。
