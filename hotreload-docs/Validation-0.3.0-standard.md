# 0.3.0-standard 验证记录

修订 `20261116-ui-polish`。基于 SSMP 0.4.142 和游戏 1.0.30000。SSMP 联机标识为 `0.3.1-std3`（随版号升位，封包结构未变，但旧版本会被拒绝）。最近核对：2026-11-15（香港时间）。

## 操作

- 念珠不足时点购买：居中窗口先问要不要借，选借款后用 ↑／↓ 挑队友、Enter 确认、Esc 回商店；金额显示为「价格 − 现有」。队友端弹同款窗口，同意后他的念珠当刻减少、买家念珠增加，模组随后自动完成购买并扣款，欠款同时写进记账本。队友拒绝时回到商品列表并提示「队友拒绝了借款，可能也没钱」。借款开关默认开启，房主可在 F7 关闭；关闭后仍可攒钱补差。
- 借款开关默认开启，房主可在 F7 关闭；关闭后仍可攒钱补差，已有欠款继续结算。存活时默认按 F1 打开或合上账本，可在联机体验的快捷键设置中改键。位置可编辑，默认显示区域名。借入方可用身上的散装念珠还款。结清划线保留，可手动删除。借款后按现实时间计 8 分 48 秒，逾期加 3 念珠。已存在的债务继续结算。离线时扣下的还款在原队友带原存档上线后交付。
- 付费长椅只提供攒钱。长椅依旧由游戏原流程解锁并通过 SSMP 共享。符合重复付款条件时，个人份额退给买家、代付份额退给队友。房主重启前若仍未结算，有错过退款的风险。
- 入房同步剧情、祈愿、地图和装备进度。需要用房主库存覆盖资源时，客机坐长椅按 F9，关闭面板后等待备份与重载。散装念珠、念珠串和记账本按个人存档保留。
- 成茧后使用游戏现有的快捷地图绑定，按住显示、松开关闭。↑／↓ 只在自己和**同场景**存活队友之间循环。**倒地等待期间停掉跟随主角的暗角贴片**，看自己的茧和看同场景队友都能看到整个场景；队友换图、倒地或离线后自动回到自己的视角并提示，不再跨场景传输画面。
- 队友传送的过程与结果改在游戏自带的发言记录里。接受方无法接待时只回两句原因：「队友移动中」「队友未在安全地面」。F7 与联机体验面板的快捷键可绑任意键盘按键，Esc、F2、F7 和当前安全脱困键保留。
- F7 面板按外观、名字、队伍与画面、队伍操作分组；没设置传送点时提示会说出该按哪个键设置，在长椅上未起身时说明传送会在起身后继续。
- 设置、删除、前往个人传送点的提示，以及队友传送的过程与结果，都出现在游戏自带的发言记录里；左下角只保留一键同步等其余操作。记账本里每条欠款都有「还款」按钮，可用散装念珠分次归还。

## 构建和自动化检查

- 重建当前修订通过，保留已有的 Newtonsoft.Json 引用统一提示。生成的 DLL 与本机游戏目录中的 DLL 字节一致。
- 全量回归通过：953 项联机封包与账本检查、745 项键位与选人检查、58 项快捷键与提示检查、567 项传送路由与封包检查、1,003 项资源和个人钱包检查、1,079 项祈愿／物品／纹章／巨门检查、348 项地图与三人模拟。
- 原生接口静态检查通过，共检查 3,282 项引用，无缺失。本轮把 `DarknessRegion` 的绑定换成 `HeroController.vignette`、`HeroController.heroLight`、`HeroLight.vignette` 三个成员，并静态确认：等待期会读取这组贴片的渲染器、按原状态隐藏并在结束时恢复、同一画面重新打开时再次压住。原生接口检查另外钉住借款链路用到的 `DialogueYesNoBox.Open`、`ShopItem.SetPurchased`、`SimpleShopMenu.ConfirmYes/ConfirmNo`；静态检查确认借款提问走游戏确认框、同意后给买家加钱并继续购买、拒绝时关掉确认框回到商品列表。键位检查同时确认观战名单按同场景筛选、`CocoonWatch*`／`CocoonFrame*` 等跨图类型已不在产物中、封包只剩 8 个标识。上述检查验证规则、封包与接口，画面效果仍需实机确认。

## 为什么这一版换了做法

前两版分别试过「把房间暗度记为 0 并播 `HERO RESPAWNED`」和「给队友复制本机光效」，实机都仍然发黑。查过游戏实现后确认：遮住画面的是**跟随主角的暗角贴片**（`HeroLight.vignette`，由 `Darkness Control` FSM 控制大小），它不是场景暗度，也不会跟着观战镜头移动；同社区「去掉暗角」模组的做法一致——停掉这组贴片的渲染。本轮因此只动渲染器，不动 FSM 与场景暗度：贴片对象保持运行，救援流程仍能把房间原本的暗度放回去。

## 实机日志与待验收项

2026-11-13 的房主日志确认加载的是 `20261113-cocoon-arrows`，同联机标识的客机连入、双人大厅准备和存档校验完成。它能证明入房与校验，不覆盖本轮改动。

- **等待期提亮（本轮重点）**：在明显偏暗的房间（如深坞、`Song_05` 附近的暗层）成茧，先看自己的茧，再按 ↑／↓ 看同场景队友——两种情况都应看到整个场景，而不是只有茧周围一圈亮。队友在房间另一端时也要能看清他在做什么。记录被救起的一瞬间房间明暗是否立即恢复；若没恢复，记下当时是否正在换图。
- 成茧地图：按住游戏的快捷地图键查看、松开关闭，键盘与手柄各测一次；观战期间打开地图再关闭，画面应仍然明亮。
- 快捷键：把传送键改到字母键、方向键或空格，确认立刻生效且不与其它联机操作冲突；Esc、F2、F7 与脱困键应被拒绝。
- 传送播报：过程与结果应出现在游戏自带的发言记录；队友在移动时请求显示「队友移动中」，队友站在空中或危险处显示「队友未在安全地面」。
- 版本一致性：各端都换成 `20261115-vignette-brightness`。联机标识未变，新旧修订理论上能同房，但两端的画面与提示会不一致，仍建议全员同步更新。
