# 0.3.1-standard 安装和使用

先退出游戏，所有端安装 0.3.1-standard（20261116-review-fixes）。用 Manifest.json 或启动日志核对各端的完整版本与修订。

主菜单左上角的完整模组列表会显示 `Silksong Coop Assist (Standard): 0.3.1`。SSMP 的附加组件校验提示中会显示 `CoopAssist v0.3.1-std3`。旧修订需要更新后才能加入该房间。

## 安装与回滚

干净游戏：从 Releases 下载 `SSMP-Enhanced-0.3.1-standard.zip`，把包内的 `BepInEx`、`.doorstop_version`、`doorstop_config.ini`、`winhttp.dll` 放到游戏根目录，与 Hollow Knight Silksong.exe 同级。包内已含 BepInEx、SSMP、ModMenu、DebugMod、中文本地化、Modlist 与字体，不含游戏本体文件，游戏版本需为 1.0.30000。

已有合作版：用同一份 `SSMP-Enhanced-0.3.1-standard.zip` 的 `BepInEx` 覆盖到游戏根目录即可，包内已带同一份 `Fonts/AaXuanYuanTi-2.ttf`。不要删除个人配置、皮肤和存档。同步目录内嵌 DLL，不另装 Python 或 JSON。

需要回滚时，所有端一起换回上一版的 `SSMP-Enhanced-<版本>.zip`，覆盖 `BepInEx` 即可。内部更新包的 `Rollback/` 里也保留了上一修订的 DLL，可作为单文件回退。先让各端结清借款和待发退款，再一起更换版本。

## 加入与同步

房主开房、队友加入后，各端先在大厅点击准备，全员准备后再选档。加入前接收新房主快照并备份已有存档，未收到快照不直接加载未同步存档。

加入时同步剧情、祈愿、地图及装备进度。个人库存与一般获取记录保留，需要覆盖时在长椅用 F9。散装念珠、念珠串、记账本及个人纹章配装各自保留。

异常恢复：客机坐长椅，在 F7 或“选项 → 模组 → 联机体验”点击“按房主一键同步”，关闭设置并留在长椅。先保存与确认备份，再同步、正常重载并重做成员校验。房主忙或等待超时则取消。额外备份在存档同目录 CoopAssist-Backups。

入房后恢复正常操作时自动保存，之后安全状态约每 30 秒补存；失败后重试。强制退出或崩溃前最后一个周期可能未落盘。

F9 使用房主存档中当前的苔莓数量。

## 念珠补差和记账本

念珠不足时点购买会弹出一个居中的借款窗口：先问「还差 N 念珠，要向队友借吗」，选「借款」后在同一窗口用 **↑／↓ 选队友、Enter 确认、Esc 返回商店**，窗口里会写清商品价格、现有念珠和需要借的数额。队友端弹同款窗口问是否借出；同意后他的念珠立刻减少、你的念珠增加，模组接着自动买下刚才那件商品并正常扣款，同时在记账本里记下这笔欠款。队友拒绝或余额不够时会回到商品列表，并提示「队友拒绝了借款，可能也没钱」。

房主可在 F7 关闭借款（默认开启）。关闭后仍可请队友攒钱补差，已有欠款继续结算。存活状态下默认按 F1 打开或合上记账本，也可以从 F7 面板打开。账本里每条欠款都有「还款」按钮，用身上的散装念珠还款；可编辑地点。现实时间 8 分 48 秒后加 3 念珠，余额和后续拾取优先还款。结清后记录划线保留，可手动删除。

## 个人传送点

站在固定安全地面按 F10 设置传送点，F11 前往，F12 删除。三个操作也在 F7 与联机体验设置中提供。旧版设置的复活点自动用作同一存档的传送点。复活走游戏的长椅流程，只有主动按键或点“前往传送点”才启动这项传送。还没设置传送点时，提示会直接告诉你要按哪个键设置；在长椅上启动传送会尝试自动起身，没有找到长椅对象时会提示传送仍在继续，起身后自动完成。

从长椅出发会尝试正常起身。角色需要恢复操作后才能传送。跨图走游戏的场景入口，到达后检查落点。场景或存档意外变化、落点危险及等待超时都会结束请求，提示写在游戏自带的发言记录里。

## 纹章与圣斐巨门

入房和 F9 同步进度时保留各自选中的纹章和槽位配置。游戏按剧情处理诅咒与纹章升级。

进房和 F9 会同步房主的末代裁决者击败、巨门已开、圣斐巨门到访及第二幕进度。在线成员校验后也会同步这些记录。收到已击败且已开门的状态后，卡在旧状态的房间会进入游戏自带的已开门分支，跳过开门过场。已经开始播放的过场继续由游戏完成。

## 共享地图

入房和 F9 同步房主拥有的地图、绘图工具及探索记录。进入房间并完成校验后，任意一人购买地图就会共享给其他在线成员，各自在自己的存档保存；不会向接收方收费，地图价格不变。新增到访／绘制房间和发现长椅也共享，自己的茧标记仍个人独立。

客机在房主回传对应记录后才停止重试。收到新区域地图时会调用游戏原有的绘图更新。

再次打开商店时已共享的地图不再显示。若同步时商店已经开着，对应旧商品会禁止重复购买并提示重新打开；首次正常购买仍走原生流程。地图到手后尽量正常退出，让异步保存完成；异常时仍可坐长椅按 F9 重新按房主同步。

## 游戏左下角提示与折叠设置

F9 按房主同步仍在游戏左下角显示操作说明、成功结果或失败原因。设置、删除、前往传送点，以及队友传送（F6）的过程与结果，改由游戏自带的发言系统播报，不再占用左下角提示。打开队友列表、上下切换、离线或取消都会报告。列表窗口下方预留提示区域。

最近三条提示从左下角向上排列，每条约 12 秒；重复文字刷新时间，避免连续操作或同步阶段瞬间覆盖。队友选择窗打开时只显示最新一条，便于看清当前目标。操作提示独立绘制，不会重复插入原生聊天行。

F7 的结果区和原生设置结果区仅作为补充查看。F7 按钮旁显示当前快捷键。可改键的操作统一放在默认收起的“快捷键设置”中。

手动同步会报告获取快照、收到快照、等待关闭设置、保存备份、重载、完成。收到提示后关闭 F7／暂停设置，并保持坐在长椅上直到重载完成；收到快照不代表同步完成。

## 队友名字颜色与字体

所有端安装同一修订，并保留随包 Fonts/AaXuanYuanTi-2.ttf。

中文及中英混合头顶名统一使用 Aa轩辕体、27 磅并关闭自动缩放；纯 ASCII 名字沿用原生字体和字号。每人的加粗选择会同步给队友，名字组件重建／换图后也会恢复；不依赖合作存档轮询是否正常运行。

F7 或联机体验菜单选择名字颜色后，会明确采用该颜色并同步到队友头顶名、地图头像和方向提示。白色现在也会发送真正的白色，避免沿用旧色；主动选择颜色会关闭“跟随披风颜色”。在原生 SSMP 设置重新开启跟随披风后，仍按该设置广播颜色。

若仍不一致，请核对各端启动日志中的完整版本、修订标识，以及 [NameColour] 的发布／接收／应用记录、[NameStyle] 的发布／接收／实际字体字号记录。缺少字体时会有 [NameFont] 警告。

## 常用操作

- F1：存活时打开或合上念珠记账本。
- F2：DebugMod。
- 游戏的快捷地图键：成茧后也可按住查看，松开关闭。使用游戏设置中的键位。
- ↑／↓：成茧后在自己与**同场景**存活队友之间循环切换。**倒地等待期间会停掉跟随角色的暗角贴片，整个场景都看得见**，看自己的茧时也一样；救援后恢复原暗度。队友换图、倒地或离线后自动回到自己的视角并提示，不再跨场景传输画面。
- F5：成茧后返回长椅，支持原手柄绑定。
- F6：打开队友传送选择窗；↑ / ↓ 或窗口中的上下按钮切换，Enter 确认，Esc 取消。鼠标可选中姓名后点“确认传送”。只有一位队友也先显示列表。
- F7：快捷面板，可滚动并固定关闭按钮；原生联机体验设置也支持滚轮、滑块和手柄焦点滚动。
- F8：存活时安全脱困。
- F9：客机坐长椅后，按房主一键同步。
- F10 设置当前安全位置为个人传送点。
- F11 前往个人传送点。
- F12 删除此存档的传送点。

记账本、成茧返回长椅、队友传送、一键同步和三个传送点操作，都可在 F7 或“选项 → 模组 → 联机体验”的“快捷键设置（展开）”中改绑任意键盘按键，互不冲突即可。Esc、F2、F7 和当前安全脱困键保留；鼠标与手柄按钮不作为快捷键。升级时若 F1 已分配给其他联机操作，保留该绑定并为账本分配空闲键。

列表包含“传送至距离最近的队友”。确认时按地图直线距离比较可定位、已同步且存活的队友；地图定位不可用时只比较同图位置，不直接比较异图场景内坐标。未知位置仍可按名字选择并请求跨图传送。最近指直线距离，不是跑图路线长度。离线、倒地、同步中、换图或不安全落点会拒绝／取消，不会自动改传其他队友。接受方无法提供落脚点时只回两种原因：队友在移动或暂时无法接待显示“队友移动中”，站的位置本身不安全显示“队友未在安全地面”。选择的队友离线后，必须重新选择目标再确认。

暂停设置中的“传送到队友…”也会打开列表，支持原生菜单的上下选择和确认／返回；确认后通过游戏正常关闭暂停菜单再执行。F7 面板提供同一操作入口。

个人皮肤与 UI、Aa轩辕体 27 磅、名字颜色等保留。队友离线后其余人可继续移动和从长椅起身，不必删联机存档标记。

实机验收项目见 Validation-0.3.0-standard.md。
