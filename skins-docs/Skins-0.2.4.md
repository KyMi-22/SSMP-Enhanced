# 0.2.4 皮肤来源与使用

新增资源取自用户已下载并解压到本机的文件，整合时仅统一皮肤包的顶层目录名，并将启用标记改为 active.txt.off。图片和视频内容、贴图所需的相对路径均保持原样。原版三个皮肤沿用 0.2.3 的已校验资源。

皮肤作品归原作者所有；作者署名、使用和再分发条件以对应原发布页为准。本包为用户的本地游戏整理，未将这些资源上传到第三方站点；这份整合不授予额外的再分发许可。

11 个可选包位于 Hollow Knight Silksong_Data/Mods/Customizer，均默认关闭。原有 GhostOfPharloom、VampireHornet、XJY 的来源说明保留在其他 Docs 文档中。

选皮肤前回到主菜单并退出房间，使用选项 → 模组 / Mods → 联机体验，或按 F7。皮肤列表可以滚动，选择后重启游戏。自己的角色及 HUD 使用自己的选择，对方的角色使用对方的选择；双方需带齐相同目录名的资源。

FieryHornet 附带 VideoClip 下两段 Bellbeast_Travel 视频。保留文件，但当前 Customizer / CustomizerT2D 组合不提供这些过场视频的替换功能。未安装额外的 CustomizerCinematic。其余皮肤也没有进行逐场景或双人游戏内的视觉验收。

检查包括 PNG 签名、尺寸、完整 chunk 边界与 CRC、文件清单 SHA256、Knight/atlas0.png 是否存在。WebM 只检查 EBML 文件头与完整文件散列，不代表游戏内可播放。资源校验不能证明每种武器、UI、特效和所有场景都兼容。
