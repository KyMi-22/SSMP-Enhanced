# 0.2.4 验证范围

本次在 0.2.3 完整包基础上更新 CoopAssist DLL 至 0.2.4，加入 8 个皮肤包并为 F7 皮肤列表增加滚动条。保留原有 3 包，共 11 包、912 张 PNG。另保留 FieryHornet 两段当前加载器不启用的 WebM。

## 检查内容

- 编译新版 DLL；核对 BepInPlugin 及客户端、服务端扩展版本为 0.2.4。
- 回归加入/观战策略、原生坐标消息、原有增强逻辑、外观消息、人物采样与显示、受击补发及动画映射的既有检查。
- 对整套运行 DLL 作静态成员引用和动态目标检查；已知旧 MonoMod 下不启用的 Reorg 适配器引用单独记录，不计为活动缺失引用。
- 校验所有 912 张 PNG 的文件头、非零尺寸、chunk 边界与 CRC、IEND；检查两个 WebM 的 EBML 文件头。没有重新编码或修改图片内容。
- 8 个新增包的每个文件与用户本地原件逐项比较 SHA256，只改变顶层包名及 active.txt 的文件名；所有 11 包默认关闭，均有 Knight/atlas0.png。
- 核对完整 ZIP 每项运行文件的大小与 SHA256、重复路径、目录越界、默认启用标记和个人文件排除。0.2.3 既有运行文件中只替换 CoopAssist DLL，所有其他既有文件保持不变。
- 检查打包的 DLL 与本次构建相同，源码与当前工作副本相同，回退 DLL 与 0.2.3 相同，原 0.2.3 发布 ZIP 未变化。

具体运行报告见 Docs/Package-Check-0.2.4.json；资源尺寸及散列清单见 Docs/SkinAssets-0.2.4.json。Manifest.json 是运行文件清单。

## 未验证

没有写入实际游戏目录、启动游戏、连接本机端口或进行双机实测。CRC 和散列验证不是 Unity 内的图片解码、贴图替换、UI 和网络外观验收。未确认所有皮肤的每个武器及特效与当前游戏版本都兼容。

本次不新增 Boss、怪物、机关、死亡或存档机制改动。0.2.3 人物与受击优化的细节及测试边界见 Validation-0.2.3.md，不将合成轨迹测试的改善当作实际联机性能保证。
